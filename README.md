# Article Voice Reader

网页划词朗读、翻译与译读扩展，可调整语速和声音。

## 安装

需要 支持 Manifest V3 的 Chrome 或 Edge。朗读可用声音由操作系统和浏览器决定。

克隆仓库后，在项目根目录执行以下步骤。

打开浏览器扩展管理页，开启开发者模式并选择「加载已解压的扩展程序」，指向本项目目录。

## 使用

刷新网页，选中文字后打开 AVR 菜单，选朗读或翻译。需要翻译服务时按扩展设置填入自己的配置。

## 检查

在普通网页选中一段文字，检查菜单、朗读与语速调节。
